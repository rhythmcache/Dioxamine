# Introduction

Welcome to the official documentation for Dioxamine.

Dioxamine is a fast, modern Android application that provides native ADB device management, wireless pairing, Scrcpy screen mirroring, Fastboot controls, and an extensible web-based Plugin System.

## Documentation Structure

This documentation is organized into key focus areas:

1. **Plugin Development Guide**: Comprehensive specifications, guides, and API documentation for building custom Dioxamine Web plugins using HTML, CSS, and JavaScript.
2. **App User Guide** (Coming soon): End-user documentation for connecting devices over USB, Wi-Fi pairing, Scrcpy configuration, and fastboot flashing.
3. **Core Architecture** (Coming soon): Internal design documentation for the Kotlin native runtime, ADB engine, and security gates.

To get started building custom modules for Dioxamine, proceed to the [Plugin Development Overview](plugins/overview.md).
