Toolchain & Core Architecture

Connectivity

Flexible transport negotiation over wired cables or local wireless networks.

>
USB OTG Host: Direct hardware cable connection with automatic device authorization. Connection guide
>
Wireless ADB: mDNS auto-discovery, Android 11+ QR pairing, 6-digit PIN codes, and TCP/IP port 5555. OEM setup

ADB Built-in Tools

Complete device management utilities running directly on the target.

>
File & Package Management: Browse storage, push and download files, install standalone APKs and split bundles (.apks, .xapk), and disable bloatware. Package manager
>
Hardware Input & Controls: Trackpad with multi-touch gestures, full PC keyboard with modifier latches, and Android TV D-pad remote. Touchpad guide
>
Maintenance: Interactive ANSI terminal shell, instant screencap capture, OTA sideloading, and power reboot targets. Terminal shell

Scrcpy 4.1 Engine

Low-latency screen mirroring and camera video forwarding.

>
Display Mirroring: H.264, H.265, and AV1 video encoding up to 60 FPS with touch forwarding and screen-off power saving. Mirroring details
>
Audio Forwarding: Opus/AAC streaming on Android 11+ and audio duplication (Don't Mute) on Android 13+. Audio settings
>
Camera Streaming: Direct sensor streaming from front, back, or external lenses at up to 120+ FPS with remote torch control. Camera mode

Fastboot Protocol

USB OTG bootloader maintenance and partition recovery.

>
Partition Flashing: Flash boot, recovery, init_boot, and system images with real-time transfer progress. Flashing guide
>
Live Boot & Lock State: Test boot kernels without permanent writes, manage bootloader unlock states, and inspect hardware variables. Live booting

Web Plugin Runtime

Modular HTML5, CSS, and JavaScript extensions.

>
Native Bridge API: Asynchronous JavaScript bridge with full access to ADB execution, shell sessions, file transfers, and device info. Bridge reference
