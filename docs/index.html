Android Toolkit & Runtime

Run ADB, Fastboot and Scrcpy directly on your phone.

Control secondary devices, mirror displays with low latency, stream camera feeds, flash Fastboot firmware over USB OTG, and execute custom Web plugins without needing a computer.

Toolchain & Core Architecture

Connectivity & Transport

Flexible transport negotiation over wired cables or local wireless networks.

>
USB OTG Host: Direct hardware cable connection with automatic device authorization and permission negotiation. Connection guide
>
Wireless ADB: mDNS auto-discovery, Android 11+ QR pairing, 6-digit PIN codes, and persistent TCP/IP port 5555. OEM setup
>
Multi-Device Scope: Seamless multi-device management with top-chip device switching across all ADB, Fastboot, and plugin sessions. Multi-device

ADB Built-in Tools

Complete device management utilities running directly on the target.

>
File & Storage Management: Full internal/external storage explorer with push, pull, recursive directory management, and Storage Access Framework (SAF) integration. File manager
>
Package Manager & Split APKs: Install standalone APKs and split bundles (.apks, .xapk, .apkm), export APKs, uninstall, and disable bloatware. Package manager
>
Hardware Input & Controls: Trackpad with multi-touch gestures (pinch, scroll, tap), full PC keyboard with sticky Ctrl/Alt/Esc/Tab modifier latches, and Android TV D-pad remote. Touchpad guide
>
Process Manager & Telemetry: Real-time CPU and memory metrics, running process inspector with one-tap termination, live streaming Logcat, and hardware battery specs. Process manager
>
Terminal & Maintenance: Interactive ANSI PTY terminal shell, instant screencap capture, OTA sideloading, rescue mode, and power reboot targets. Terminal shell

Scrcpy 4.1 Engine

Low-latency screen mirroring and camera video forwarding.

>
Display Mirroring: H.264, H.265 (HEVC), and AV1 video encoding up to 120 FPS with touch forwarding, mouse simulation, and screen-off power saving. Mirroring details
>
Audio Forwarding: Opus/AAC streaming on Android 11+ and non-muting audio duplication on Android 13+. Audio settings
>
Camera Streaming: Direct hardware sensor streaming from front, back, or external lenses at high framerates with remote torch control and zoom. Camera mode
>
Session Recording: Direct MP4 recording of mirroring or camera streams directly to device storage with in-app playback viewer and export. Recording guide

Fastboot Protocol

USB OTG bootloader maintenance and partition recovery.

>
Partition Flashing: Flash boot, recovery, init_boot, vendor_boot, system, and super images with real-time transfer progress. Flashing guide
>
Live Boot & Lock State: Test boot kernels without permanent writes, manage bootloader unlock states, and inspect hardware variables. Live booting
>
Variables & Command Shell: Inspect full hardware device variables (getvar all), partition erase, slot switching (set_active a/b), and custom raw command execution. Variables inspector

Web Plugin Runtime

Modular HTML5, CSS, and JavaScript extensions with rich native bridge.

>
Native Bridge API: Asynchronous JavaScript runtime (window.dioxamine) connecting web applications directly to native ADB and Fastboot drivers without a computer. Bridge reference
>
Interactive Shell Streams (PTY): Bi-directional live terminal streaming via dioxamine.adb.openInteractiveShell() with dynamic window resizing and full xterm.js integration. Interactive shell
>
Native Haptics & UI Controls: Native tactile feedback API (dioxamine.haptics.impact(), dioxamine.haptics.selection(), dioxamine.vibrate()) and hardware Back/Volume button interception. Haptics & UI
>
Fastboot Protocol Operations: Flash partitions, reboot targets, inspect variables, and stage binary payloads directly from plugin JavaScript. Fastboot API
>
Chunked Storage & HTTP Fetch: Chunked temporary file streams (dioxamine.tempFile) for streaming gigabyte payloads without RAM limits, and zero-CORS network requests via dioxamine.http.fetch(). File operations
>
Plugin Store & Auto-Updates: In-app registry to browse, install, and automatically update plugins (updateJson) with an open community submission pipeline. Plugin updates
